# Sound effects

These cues come from Robin Lamb's **UI Sound Effects (Button Clicks, User Feedback, Notifications)** pack:

https://opengameart.org/content/ui-sound-effects-button-clicks-user-feedback-notifications

The pack is released under CC0. Its sounds were sourced from the public-domain VCSL and VSCO 2 CE instrument sample libraries and edited in Audacity.
